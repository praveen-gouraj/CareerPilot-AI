Project Overview

AI-Based Career Guidance and Placement System using KNN and NLP

This platform combines Flask, scikit-learn, NLP, session authentication, and a modern dashboard UI to help students assess career fit, identify skill gaps, review resumes, and practice interviews in one place.

Full Stack
Frontend, backend, ML, NLP, analytics
Machine Learning

A KNN model predicts the best career domains from the selected skill profile.

NLP Resume Review

Resume text is extracted, keywords are matched, and ATS-style scoring is generated.

Placement Analytics

Charts and progress views summarize readiness, interview performance, and career recommendations.

Admin Controls

Administrators can manage users, domains, and interview question banks from the secure panel.
